# UET History Status Report

**Status date:** 2026-07-08

## Current Public State

`uet_history/` is now treated as a curated history and publishing workspace, not
a raw dump of every historical note or media asset.

## Active Public Layers

| Layer | Public path | State |
| --- | --- | --- |
| Digest | `2_digest/` | Scaffolded public-safe registry and orientation. |
| Publish | `3_publish/` | Public-facing book and narrative workspace scaffold. |
| Raw | local `1_raw/` | Excluded from public repo by default. |

## Current Boundary

The public tree should show where the work is going without exposing raw chat
exports, private notes, old archives, ZIPs, videos, PDFs, or large media.

Next useful work is to promote selected material from local raw/history into
small reviewed digest or publish files, one scoped batch at a time.
