# 0.1 history_media_and_cold_war (ประวัติศาสตร์สื่อ สถิตอำนาจ และสงครามเย็น)

นี่คือ Workspace หลักสำหรับรวบรวมข้อมูล, โครงร่าง และต้นฉบับของ **หนังสือเล่มที่ 3.1** ในมหากาพย์ UET (Section 3: History & Hegemony)

## โครงสร้างโฟลเดอร์ทำงาน (Standard Book Structure)

*   **`1_raw/`**: สำหรับใส่ข้อมูลดิบทั้งหมด (ไฟล์แชทประวัติศาสตร์, ข่าวสาร, เอกสารประวัติศาสตร์สื่อ/สงครามเย็น)
*   **`2_digest/`**: สำหรับสรุปแก่นประเด็นและโน้ตวิเคราะห์
*   **`ch_drafts/`**: สำหรับใช้เขียนและเก็บต้นฉบับแยกรายบท (Chapter Drafts)
*   **`book_blueprint.md`**: โครงร่างและพิมพ์เขียวหลักของหนังสือ

## แก่นประเด็นของเล่มนี้
*   **บริบทสื่อและการสร้าง Perception:** การทำ Propaganda และการสร้างสื่อตั้งแต่ายุคกลาง (ระบอบศักดินา/อำนาจนิยม) จนถึงยุคสงครามเย็น
*   **การปั่นการรับรู้ (Manufactured Consent):** ทำความเข้าใจว่ามหาอำนาจ สื่อมวลชน และวาทกรรมสงครามเย็นสร้างกรอบการรับรู้ของสังคมมนุษย์ขึ้นมาอย่างไร
