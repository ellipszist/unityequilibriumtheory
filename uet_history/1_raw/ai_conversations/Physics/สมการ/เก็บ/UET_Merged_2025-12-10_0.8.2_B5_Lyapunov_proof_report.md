## Part A3 — B: `A3_calibration_plan.md` (content)

### TL;DR
แผนสอบเทียบรวม (calibration plan) ระบุ: (1) ชุดการทดลอง/การวัดที่ต้องการ, (2) รูปแบบ likelihood ที่ใช้ (เริ่มจาก Gaussian errors), (3) กระบวนการ Bayesian calibration (prior, sampler, diagnostics), (4) ตัวย่อ pseudocode สำหรับ MCMC และ Ensemble Kalman Filter (EnKF) เพื่อใช้งานจริง

---

### 1) เป้าหมายการสอบเทียบ
- หา posterior distribution ของพารามิเตอร์ \(\theta = (\alpha,\beta\sigma,\delta,\kappa,\hbar_C,\lambda',k_C,k_{\Psi})\)
- ให้ค่ากลาง (MAP) + credible intervals พร้อมตรวจสอบ stability (Ω decreasing, boundedness)

---

### 2) ข้อมูล/การทดลองที่ต้องใช้ (observables)
- **Thermal-information experiment:** วัด throughput R (bits/s), dissipated heat P_heat (J/s), และสภาพแวดล้อม T. ให้ชุดข้อมูลเวลาที่มี R(t), P_heat(t).
- **Controlled communication field (lattice) sweep:** เซ็ตค่าฟลักซ์ \(\Phi_{info}\) แบบคงที่หรือ ramp แล้ววัด E_total(t), relaxation time τ, และค่าคงตัว C_eq (equilibrium C) ในกริด
- **Quantum coherence probe:** วัด energy contribution ที่มาจาก coherence (spectroscopy/coherence times) เพื่อประเมิน \(\hbar_C\) และ \(\kappa\)

For each experiment, collect measurement error estimates (σ) or derive them from repeated trials.

---

### 3) Likelihood model (starting point)
ใช้ Gaussian observation model (can be adapted):

For observable y (vector) and model prediction f(θ):

\[ p(y|\theta) = \mathcal{N}(y; f(\theta), \Sigma) \]

- Σ may be diagonal (measurement errors) or include correlations (if known)
- For count/rate data (bits counts), consider Poisson / Negative Binomial if shot noise dominates

---

### 4) Prior choices (physically informed)
- δ: prior support (0, +∞) — log-normal or half-normal with median near suggested_initial
- α, βσ: normal/log-normal around suggested_initial (positive-centered) with wide variance
- κ, ℏ_C: log-normal (positive) with wide prior reflecting uncertainty
- λ': Beta(α=1,β=9) as initial belief that semantic fraction is small (adjustable)

Document priors explicitly in code/config.

---

### 5) Calibration algorithms
**Primary (batch) — Bayesian MCMC**
- Build model: y_obs ~ Normal(f(θ), σ_obs)
- Use surrogate (GP) for f if full model expensive
- Sampler: emcee or pymc3/NUTS (if continuous differentiable)
- Diagnostics: R_hat, effective sample size, posterior predictive checks (PPC)

**Alternative / sequential — Ensemble Kalman Filter (EnKF)**
- Useful for online calibration where data arrives in time series
- Ensemble of parameter particles updated using Kalman-like update on states+params
- Fast but approximate (Gaussian assumptions)

---

### 6) Pseudocode — Bayesian MCMC (with surrogate)
```
# 1. Generate training samples from prior (Latin Hypercube) -> param_set
# 2. Run full model f(theta) for training set -> build dataset (theta, f)
# 3. Train surrogate model (GP) to emulate f
# 4. Define likelihood: y ~ Normal(GP(theta), sigma_obs)
# 5. Run MCMC sampler (NUTS / emcee) using GP in place of f
# 6. Posterior diagnostics + posterior predictive checks
# 7. Optionally refine GP by adding new training points near high posterior density (active learning)
```

---

### 7) Pseudocode — Ensemble Kalman (EnKF) for sequential data
```
# Initialize ensemble of N particles theta_i ~ prior
# For each observation time t with y_t:
#  1. For each ensemble member, run model forward to obtain predicted y_t_i
#  2. Compute ensemble mean and covariances
#  3. Kalman update: theta_i <- theta_i + K (y_t + eps_i - y_t_i)
#     where K = Cov_theta_y * Cov_y^{-1}
#  4. Optionally add inflation/noise to maintain ensemble spread
# After full sequence: compute ensemble mean, cov as posterior approx
```

Notes: implement localization if spatial domain large; use adaptive inflation to avoid collapse.

---

### 8) Diagnostics & validation
- Posterior predictive checks: simulate model at posterior samples and compare to held-out data
- Stability verification: for posterior samples, check Ω(t) monotonic decrease and boundedness in forward runs
- Sensitivity re-assessment: run Sobol on posterior to find remaining important parameters

---

1. `A3_parameter_ranges.yaml` (as above)
2. `A3_calibration_plan.md` (this document)
3. `A3_prior_config.json` (machine readable prior specs) — optional next step
4. Example Jupyter notebook skeleton: `notebooks/A3_calibration_pipeline.ipynb` (pseudocode + small emulation)

---

### 10) Practical notes & recommended tools
- Bayesian: pymc3/pymc (NUTS), emcee, or stan
- Surrogate: scikit-learn GP, GPyTorch for scalable GP
- Sensitivity: SALib (Sobol)
- EnKF: DAPPER or custom implementation

# UET 0.8.2 — Part B3: Draft Ω (Omega) functional (v0.8.2)

---

## TL;DR
ร่างสมการ Omega เวอร์ชัน 0.8.2 ที่สอดคล้องกับ Part A2/A3 (หน่วยล็อกแล้ว) พร้อมนิยามพารามิเตอร์ หน่วย เงื่อนไขความเสถียรแบบคร่าว ๆ และแผนการพิสูจน์ Lyapunov แบบเป็นขั้นตอน ไฟล์นี้เป็นร่างที่ต้องใช้เป็นฐานสำหรับ B4–B5 (stability proof) และ C (Lagrangian).

---

## 1. Statement — Ω functional (compact form)
\[
\boxed{\;\Omega[ C,\Psi ] \;=\; E - C\,(S_{\rm comm}-\lambda' I_{\rm sem}) + \Phi(C)
\;+\; \hbar_C\,\int_V |\Psi|^2\,dV 
\;+\; \kappa\int_V |\nabla\Psi|^2 \,dV \;+\; \mathcal{R}[C,\Psi] \; }\]

where:
- \(E\) — total base energy (J).  
- \(C\) — dimensionless normalized flux (see A2) such that measured flux \(\Phi_{info}=C\,C_0\) (bits/(m^2·s)).  
- \(S_{\rm comm}, I_{\rm sem}\) — energetic forms (J) of communication/semantic information; obtain via Landauer mapping from bits or bits/s.  
- \(\Phi(C)\) — interaction/potential energy (J), e.g. polynomial: \(\Phi(C)=\tfrac{\alpha}{2}C^2 + \tfrac{\delta}{4}C^4 + \dots\).  
- \(\hbar_C\) — effective communication Planck constant with units J·s/bit normalization such that \(\hbar_C\int|\Psi|^2 dV\) has units J.  
- \(\kappa\) — gradient stiffness with units J·m^2·s/bit mapping \(\int|\nabla\Psi|^2 dV\) → J.  
- \(\mathcal{R}[C,\Psi]\) — remainder interaction terms (dissipation, coupling, surface terms), specified below.

Notes:
- All integrals over domain \(V\) (or per-unit-volume if intensive).  
- By construction each term has units of energy (J).

---

## 2. Explicit candidate form (practical, ready-for-analysis)
Choose polynomial potential and local coupling terms:

\[
\Omega[ C,\Psi ] = E - C\bigl(S_{\rm comm}-\lambda' I_{\rm sem}\bigr)
+ \frac{\alpha}{2}C^2 + \frac{\delta}{4}C^4
+ \hbar_C\int_V |\Psi|^2\,dV + \kappa\int_V |\nabla\Psi|^2\,dV
+ \gamma\int_V C|\Psi|^2\,dV
\]

- The new coupling \(\gamma\) (units J per (bit·(bits/s)?) — see unit mapping below) captures energy coupling: presence of communication coherence affects collective potential.
- The sign/role of \(\gamma\) must be determined by physical modeling; include as tunable parameter (can be positive or negative).

---

## 3. Units & consistency checklist (per-term)
(Assume \(S_{\rm comm}, I_{\rm sem}\) are energies over Δt or energy densities multiplied by volume/time as appropriate.)

1. \(-C(S_{\rm comm}-\lambda' I_{\rm sem})\): \(C\) dimensionless → product units = J. If S_comm provided as bits/s, convert: \(S_{\rm comm(J)} = S_{\rm comm(bits/s)}\cdot k_B T \ln2 \cdot \Delta t\).

2. \(\tfrac{\alpha}{2}C^2\), \(\tfrac{\delta}{4}C^4\): \(\alpha,\delta\) must be J (since C dimensionless).

3. \(\hbar_C\int |\Psi|^2 dV\): if \(|\Psi|^2\) has units bits/s per unit volume, and integration over V·Δt returns bits, choose \(\hbar_C\) such that J = (J·s/bit) · (bits/s)·s = J. Equivalently \(\hbar_C\) has unit J·s/bit.

4. \(\kappa\int |\nabla\Psi|^2 dV\): if \(|\nabla\Psi|^2\) has units (bits/s)/m^2, then choose \(\kappa\) units J·m^2·s/bit.

5. \(\gamma\int C|\Psi|^2 dV\): choose \(\gamma\) units J·s/bit (or scaled so product yields J when integrating over Δt).

Action: every time a discrete measurement is used, supply Δt and T_ref used for Landauer conversion in metadata.

---

## 4. Remainder terms & dissipation (\(\mathcal{R}\))
Include optional dissipative or control terms needed for gradient-flow/Lyapunov structure and physical realism:

\[
\mathcal{R}[C,\Psi] = \eta_C\,\|\nabla C\|^2_{L^2} + \int_V \Gamma(C,|\Psi|^2)\,dV + \text{boundary terms}
\]

- \(\eta_C\) controls spatial smoothing of C (units J·m^2).  
- \(\Gamma\) may include sink/source terms (J) representing dissipation to environment.

Design rule: include only terms that preserve \(\Omega\) as an energy-like Lyapunov functional under chosen dynamics (see §6).

---

## 5. Dynamics (gradient flows) — canonical choice
We adopt dissipative gradient dynamics for state variables (simple, physically interpretable):

**C (local, scalar)**
\[ \partial_t C = -k_C\,\frac{\delta \Omega}{\delta C} + \xi_C \]
where \(k_C>0\) is mobility (1/(J·s) scaling to yield units 1/s), and \(\xi_C\) is optional stochastic forcing.

**Ψ (diffusive/relaxational or Schrödinger-type depending on regime)**
Two sensible choices:

- Dissipative (complex Ginzburg–Landau style):
  \[ \partial_t \Psi = -k_\Psi\,\frac{\delta\Omega}{\delta \bar\Psi} + \xi_\Psi.\]
  This yields evolution that reduces \(\Omega\) monotonically (with appropriate boundary conditions).

- Conservative + damping (if quantum-like dynamics desired):
  \[ i\hbar_C \partial_t \Psi = \frac{\delta \Omega}{\delta \bar\Psi} - i\Gamma\Psi.\]
  This admits wave/phase dynamics; add small damping to allow relaxation to energy minima.

Choose the variant appropriate for the physical regime; dissipative form is simplest for gradient/Lyapunov proofs.

---

## 6. Lyapunov / monotonicity sketch (for dissipative dynamics)
Assume dissipative gradient flows:

\[
\partial_t C = -k_C\frac{\delta\Omega}{\delta C},\qquad \partial_t \Psi = -k_\Psi\frac{\delta\Omega}{\delta \bar\Psi}.
\]

Compute time derivative:
\[
\frac{d\Omega}{dt} = \int \frac{\delta\Omega}{\delta C}\partial_t C\,dV + \int \frac{\delta\Omega}{\delta\Psi}\partial_t\Psi\,dV + \text{c.c.}
\]
Substitute flows →
\[
\frac{d\Omega}{dt} = -k_C\int \Big|\frac{\delta\Omega}{\delta C}\Big|^2 dV - k_\Psi\int \Big|\frac{\delta\Omega}{\delta\Psi}\Big|^2 dV \le 0.
\]
Provided boundary terms vanish or are dissipative, \(\Omega\) is nonincreasing. This yields a Lyapunov functional and ensures trajectories approach attractors (minima of \(\Omega\)).

Caveat: requires \(k_C,k_\Psi>0\) and that \(\delta\Omega/\delta(\cdot)\) exist and are square-integrable. Nonconvex \(\Phi(C)\) (e.g., δ<0) allows multiple minima (multi-stability) but does not invalidate monotonicity.

---

## 7. Stability & boundedness conditions (practical criteria)
To ensure global boundedness and avoid runaway:

1. **High-order dominance:** quartic coefficient \(\delta>0\) (or higher even-order growth) → ensures \(\Phi(C)\to+\infty\) as |C|→∞.  
2. **Positive stiffness:** \(\kappa>0\) and \(\hbar_C>0\).  
3. **Mobility positivity:** \(k_C,k_\Psi>0\).  
4. **Dissipative boundary conditions** (e.g., Neumann or decaying fields) so surface terms do not inject energy.  

If these are satisfied, combined with finite initial energy, forward solutions remain bounded; formal proof requires functional-analytic details (PDE Sobolev estimates) — see B4/B5 tasks.

---

## 8. Practical nondimensionalization recipe
Pick reference energy \(E_{ref}\) (A3) and length L_ref; define nondimensional variables:

\(\tilde C = C\) (already dimensionless), \(\tilde x = x/L_{ref}\), \(\tilde \Psi = \Psi/\Psi_{ref}\) where \(\Psi_{ref}^2 = E_{ref}/\hbar_C\) (so \(\hbar_C\int |\tilde\Psi|^2 d\tilde V\sim E_{ref}\)). Scale parameters accordingly: \(\tilde\alpha=\alpha/E_{ref},\,\tilde\delta=\delta/E_{ref},\,\tilde\kappa=\kappa/(E_{ref}L_{ref}^{-2}),\) etc. Use these tilde-parameters for numerical sweeps.

---

# UET 0.8.2 — Part B4: Variational derivatives & Lyapunov proof sketch

---

## TL;DR
นี่คือเอกสาร B4 ที่ให้: (1) คำนวณเชิงสัญลักษณ์ของอนุพันธ์เชิงแปร \(\delta\Omega/\delta C\) และ \(\delta\Omega/\delta\overline{\Psi}\); (2) กำหนดพื้นที่ฟังก์ชันเชิงวิเคราะห์ (Sobolev spaces) ที่เหมาะสม; (3) แสดงเลมม่า/องค์ประกอบที่จำเป็นสำหรับการพิสูจน์ boundedness และ Lyapunov property; (4) วางแผนพิสูจน์อย่างเป็นระบบ (ขั้นตอนพร้อมหมายเหตุทางเทคนิค) เพื่อให้เสร็จใน Part B5.

---

## Insight (สำคัญที่สุด)
ถ้าเรากำหนด \(\Omega[ C,\Psi ]\) ตาม B3 (polynomial \(\Phi(C)\), coupling \(\gamma\), quantum term \(\hbar_C\int|\Psi|^2\), gradient term \(\kappa\int|\nabla\Psi|^2\)), และเลือก dynamics แบบ dissipative gradient flow แล้วการพิสูจน์ว่า \(d\Omega/dt\le0\) เป็นเรื่องตรงไปตรงมา แต่อย่างไรก็ตาม **การพิสูจน์ boundedness (global existence & a priori bounds)** ต้องการการวางกรอบเชิงฟังก์ชัน-อะนาลิซิส (แสดง coercivity ของ \(\Omega\) หรือสร้าง Lyapunov estimate โดยใช้ Sobolev inequalities และ Grönwall) — เอกสารนี้สรุปชุดทฤษฎีและขั้นปฏิบัติที่จะนำไปสู่ B5.

---

## 1. Explicit functional (recall B3 candidate)
(ใช้ notation เดียวกับ B3)

\[
\Omega[C,\Psi]=E - C(S_{\rm comm}-\lambda' I_{\rm sem}) + \frac{\alpha}{2}C^2 + \frac{\delta}{4}C^4 + \hbar_C\int_V |\Psi|^2\,dV + \kappa\int_V |\nabla\Psi|^2\,dV + \gamma\int_V C|\Psi|^2\,dV + \mathcal{R}[C,\Psi].
\]

คำอธิบาย: \(C\) ถูกมองเป็นฟังก์ชันสเปซ \(V\to\mathbb{R}\) (อาจคงที่/เชิงพื้นที่) หรือเป็นตัวแปรในแต่ละตำแหน่ง; \(\Psi:\,V\to\mathbb{C}\).

---

## 2. Variational derivatives (symbolic)
คำนวณเชิงสัญลักษณ์โดยถือ \(C\) และ \(\Psi\) เป็นตัวแปรที่ไม่ขึ้นกับเวลาในขั้นตอนการหาอนุพันธ์

### 2.1 \(\delta\Omega/\delta C\)
ใช้งานกฎการอนุพันธ์แบบฟังก์ชันนัล:

\[
\frac{\delta\Omega}{\delta C}(x) = -\bigl(S_{\rm comm}-\lambda' I_{\rm sem}\bigr) + \alpha C(x) + \delta C(x)^3 + \gamma |\Psi(x)|^2 + \frac{\delta \mathcal{R}}{\delta C}(x).
\]

ถ้า \(\mathcal{R}\supset \eta_C (-\Delta C)\) (พื้นที่ smoothing) เทอมที่ผูกคือ \(\delta\mathcal{R}/\delta C = -\eta_C\Delta C\) (ขึ้นอยู่กับ BCs).

### 2.2 \(\delta\Omega/\delta\overline{\Psi}\) (conjugate variational derivative)
สำหรับ \(\Psi\) complex:

\[
\frac{\delta\Omega}{\delta\overline{\Psi}}(x) = \hbar_C\Psi(x) - \kappa \Delta\Psi(x) + \gamma C(x)\Psi(x) + \frac{\delta\mathcal{R}}{\delta\overline{\Psi}}(x).
\]

(ตรวจสอบสัญญาณข้างหน้า — เราใช้นิยามโดยให้ \(\int |\nabla\Psi|^2 = \int \nabla\overline{\Psi}\cdot\nabla\Psi\) ที่ให้ผลลัพธ์ \(-\Delta\Psi\) เมื่ออนุพันธ์)

**หมายเหตุ:** ความต่อเนื่องของเทอม boundary ต้องกำหนด (Neumann/Dirichlet/decay); สมการข้างต้นถือสำหรับ BC ที่ทำให้ปริพันธ์เชิงขอบหายไป.

---

## 3. Euler–Lagrange-type gradient-flow dynamics (dissipative choice)
ใช้ dynamics แบบ dissipative (ง่ายสุดสำหรับ Lyapunov argument):

\[
\partial_t C = -k_C \frac{\delta\Omega}{\delta C},\qquad \partial_t\Psi = -k_\Psi \frac{\delta\Omega}{\delta\overline{\Psi}}.
\]

แทนค่าอนุพันธ์จาก §2 จะได้ PDE คู่:

\[
\partial_t C = k_C\Big( S_{\rm comm}-\lambda' I_{\rm sem} - \alpha C - \delta C^3 - \gamma |\Psi|^2 + \eta_C\Delta C - ...\Big)
\]

\[
\partial_t\Psi = -k_\Psi\Big(\hbar_C\Psi - \kappa\Delta\Psi + \gamma C\Psi + ...\Big).
\]

(เติมเทอมรบกวน/noise ได้เพิ่ม \(\xi\) ถ้าจำเป็น)

---

## 4. Function spaces & assumptions
ระบุขอบเขตฟังก์ชันที่ต้องการสำหรับการพิสูจน์

- **Domain \(V\subset \mathbb{R}^n\)**: ปกติ \(n=1,2\) หรือ \(3\) ขึ้นกับการจำลอง; proofs ต้องระบุพฤติกรรมต่างกันตามมิติเนื่องจาก Sobolev embeddings
- **Spaces:**
  - \(C(\cdot,t) \in L^2(V) \cap L^4(V)\) (ต้องการควบคุมพจน์ \(C^4\)). ถ้ามี spatial derivatives ก็ให้ \(C\in H^1(V)\).
  - \(\Psi(\cdot,t) \in H^1(V;\mathbb{C})\) (พอที่จะนิยาม \(\int |\nabla\Psi|^2\))
- **Boundary conditions:** Neumann (zero flux) หรือ Dirichlet ที่เหมาะสม เพื่อให้ surface integrals หายไป
- **Regularity assumptions on data:** initial data \(C_0\in H^1\cap L^4\), \(\Psi_0\in H^1\) etc.

---

## 5. Lemmas & analytical tools required
รายการ lemma ที่เราจะใช้อย่างชัดเจนใน B5:

1. **Poincaré inequality (if domain bounded & Dirichlet)**: controls \(L^2\) norm by \(H^1\) semi-norm.
2. **Gagliardo–Nirenberg interpolation**: control \(L^4\) norms (for quartic) by combinations of \(L^2\) and \(H^1\) norms. Example (in 1D/2D with proper exponents):
   \(\|u\|_{L^4}^4 \le C\|u\|_{L^2}^{2\theta}\|\nabla u\|_{L^2}^{2(1-\theta)}\) for suitable \(\theta\).
3. **Young's inequality**: to absorb mixed terms (e.g., coupling \(\gamma \int C|\Psi|^2\)).
4. **Elliptic estimates**: control of \(\|\Delta\Psi\|_{L^2}\) from \(\|\nabla\Psi\|_{L^2}\) in appropriate spaces.
5. **Grönwall inequality**: to turn differential inequalities into bounds in time.
6. **Sobolev embedding**: to embed \(H^1\hookrightarrow L^p\) for p depend on n.

---

## 6. Core proof strategy (stepwise plan for B5)
นี่คือลำดับขั้นตอนเพื่อพิสูจน์ว่า \(\Omega(t)\) เป็น Lyapunov functional และว่าโซลูชันยังคงอยู่ในขอบเขตเวลาต่อเนื่องภายใต้สมมุติฐานที่ตั้งไว้

**Step 1 — Formal monotonicity (algebraic)**
- Substitute flows into time derivative of \(\Omega\) to obtain
  \(d\Omega/dt = -k_C\int |\delta\Omega/\delta C|^2 - k_\Psi\int |\delta\Omega/\delta\Psi|^2 \le 0\) (boundary terms assumed dissipative/zero).  
- This establishes nonincrease of \(\Omega\) formally.

**Step 2 — A priori L^2 / H^1 estimates**
- Use definition of \(\Omega\) and assumption \(\delta>0,\kappa>0,\hbar_C>0\) to show coercivity: there exists constants a,b>0 s.t.
  \(\Omega \ge a\|\Psi\|_{H^1}^2 + b\|C\|_{L^4}^4 - C_0\) where \(C_0\) depends on data S_comm etc.
- Derive differential inequalities for \(\|C\|_{L^2}^2\) and \(\|\Psi\|_{H^1}^2\) using PDEs and multiply-by-test-function technique (energy method).

**Step 3 — Control coupling terms**
- Handle \(\gamma\int C|\Psi|^2\) using Young + Gagliardo–Nirenberg to absorb into coercive terms (choose \(\epsilon\)-splitting).

**Step 4 — Grönwall & global bounds**
- Combine inequalities to produce
  \(\frac{d}{dt}Y(t) \le C_1 - C_2 Y(t)\) or \(\frac{d}{dt}Y(t) \le C_3 Y(t)\) depending on sign structure, where \(Y(t)\) aggregates norms. Apply Grönwall to conclude global-in-time bounds under constraints on parameters.

**Step 5 — Existence & uniqueness (sketch)**
- For well-posedness: use Galerkin approximation (Faedo–Galerkin), derive uniform a priori bounds, pass to limit to get weak solution; uniqueness under extra regularity (Lipschitz nonlinearity control).

**Step 6 — Conclude Lyapunov stability**
- With boundedness and monotonicity, show omega-limit sets lie in critical points of \(\Omega\); discuss asymptotic behaviour and multi-stability in nonconvex \(\Phi\).

---

## 7. Edge cases & remarks
- **If \(\delta<0\)**: quartic term no longer coercive; need higher-order even term or restrain parameter regime to avoid blow-up. Bifurcation analysis required (we did analytic fold curves for 0D toy).
- **If using Schrödinger-like dynamics for \(\Psi\)**: monotonicity fails in unitary limit; one must add damping term (\( -i\Gamma\Psi\) or negative imaginary part) to obtain energy decay — proofs more delicate.
- **High dimension (n≥3)**: Sobolev embeddings change; quartic growth may be critical/subcritical — proofs may require different exponents/higher-order regularization.

## Insight (core claim)
Under dissipative gradient flows
\(\partial_t C = -k_C \delta_C\Omega,\; \partial_t\Psi = -k_\Psi \delta_{\bar\Psi}\Omega\)
with positive mobilities and coercive energy terms (quartic term δ>0, κ>0, ℏ_C>0), the functional Ω is a Lyapunov functional (nonincreasing) and solutions starting from sufficiently regular initial data remain globally bounded in the natural energy space. The proof combines algebraic monotonicity (B4), coercivity of Ω, coupling control via interpolation and Young inequalities, and Grönwall to yield a priori bounds.

## 1. Precise theorem (to be proved)
**Theorem (informal).** Let V be a bounded domain in ℝ^n (n≤2 for simplest embedding constants; extensions to n=3 discussed). Suppose parameters satisfy:
- δ > 0, κ > 0, ℏ_C > 0,
- k_C > 0, k_ψ > 0,
- boundary conditions are Neumann or periodic (so boundary integrals vanish),
- initial data C₀ ∈ H¹(V) ∩ L⁴(V), Ψ₀ ∈ H¹(V; ℂ).

Then the dissipative gradient-flow system admits a global weak solution (C,Ψ) with
\[C ∈ L^∞(0,T;L^2(V)) ∩ L^4(0,T;L^4(V)),\qquad Ψ ∈ L^∞(0,T;H^1(V))\]
for any T>0, and Ω(t) is nonincreasing. Moreover there exists M(T) finite s.t. the above norms are bounded by M(T).

*Goal:* turn this into a rigorous proof (B5) with explicit inequalities and constants.

## 2. Strategy & roadmap (step-by-step)
**Step A — Monotonicity (algebraic).** From B4 substitution show
\(dΩ/dt = -k_C∥δ_CΩ∥²_{L²} - k_ψ∥δ_{\barΨ}Ω∥²_{L²} ≤ 0\) (mod boundary terms). This is formal but exact under H¹ regularity.

**Step B — Coercivity estimate (lower bound).** Show existence of constants a>0,b>0 and C₀ s.t.
\(Ω[C,Ψ] ≥ a∥Ψ∥_{H^1}^2 + b∥C∥_{L^4}^4 - C₀.\)
Provide explicit derivation: split Ω, bound linear terms (−C S) by ε∥C∥_{L^4}^4 + C_ε via Hölder+Young; use Poincaré/Gagliardo–Nirenberg to relate norms.

**Step C — Energy inequality for norms.** Derive differential inequalities for Y(t) := A∥Ψ∥_{H^1}^2 + B∥C∥_{L^2}^2 (choose A,B>0). Multiply PDE for C by C and integrate; multiply PDE for Ψ by −Δ\barΨ or by \barΨ as appropriate to extract H¹-energy. Use coupling control lemma to absorb mixed terms.

**Step D — Close the estimates & Grönwall.** Combine inequalities to obtain
\(dY/dt ≤ K_1 - K_2 Y + K_3 Y^{p}\) where p<2 in subcritical regimes (for n≤2). Choose parameters or use interpolation to ensure K_3 Y^{p} can be absorbed or controlled, then apply Grönwall (or differential inequality theory) to obtain global bound.

**Step E — Existence via Galerkin.** Construct Faedo–Galerkin approximations, derive uniform-in-N estimates using prior steps, pass to limit to obtain weak solution. Use monotonicity to deduce time-continuity and convergence of Ω.

**Step F — Uniqueness/regularity.** Prove uniqueness under additional Lipschitz-like conditions or higher regularity.

## B. Detailed measurement protocols (per-parameter)

### 2) \(\kappa\) — Gradient stiffness
**Goal:** หาอัตราแปลงระหว่างพลังงาน gradient กับสเกลเชิงพื้นที่ของ field

**Protocol (lattice experiment):**
1. เตรียม discrete grid (sensor array) over area A. Ensure sensors measure local information flux and local dissipated power (calorimetric elements or energy meters).

3. Measure steady-state |Ψ|^2 profile and local energy dissipation E(x) for each drive amplitude.
4. Compute discrete gradient norm \(||\nabla \Psi||^2 = \sum_{cells} (\Psi_{i+1}-\Psi_i)^2 / dx^2\).
5. Fit model: E_grad_total = κ * ||\nabla Ψ||^2 + offset (other energy terms). Extract κ by linear regression (with intercept capturing background energy).

**Instruments:** spatial energy sensors (micro-calorimeters / thermopiles / sensitive power meters), high-resolution spatial sampler for bitflux (antenna/photodiode arrays or electronic capture), synchronized acquisition

### 3) \(\hbar_C\) — Effective communication Planck constant
**Goal:** หาสเกลพลังงานที่สัมพันธ์กับความหนาแน่นของโหมด coherent (|Ψ|^2)

**Protocol (quantum-coherence probe):**
1. Use a quantum testbed capable of sustaining coherent modes (e.g., superconducting qubit array, cold-atom BEC, photonic cavity array). The setup must allow controlled injection of information-like excitations and measurement of coherent energy.

   \[ \hbar_C = \frac{E_{coh}}{\int |\Psi|^2 dV}. \]

**Instrumentation:** quantum hardware (qubits/cavities), high-resolution spectrometer, calibrated energy measurement (bolometer, nano-calorimeter), field amplitude readout

**Notes:** High experimental complexity — requires specialized lab. Ensure separation between coherent energy and thermal/dissipative background by repeated baseline subtraction and controls.

### 4) \(\alpha, \beta\sigma, \delta\) — Potential polynomial coefficients
**Goal:** Fit Ω(C) functional shape from controlled C sweeps and extract polynomial coefficients

**Observables:** measured Ω_est (J) per controlled C value

**Protocol (controlled C sweep):**
1. For series of controlled Φ_info values, compute normalized C = Φ_info / C_0.
2. For each C_i, run until steady-state (or measure transient if dynamic fit desired), measure total system energy E_total and compute Ω_est = E_total - C*(S_comm - λ' I_sem) + (other known terms).
3. Build dataset {C_i, Ω_est_i} across range 0 ≤ C ≤ C_max (ensure large enough to capture quartic behavior).
4. Fit Ω(C) to model: Ω(C) = E0 + (α/2) C^2 + (βσ/2) C^2 + (δ/4) C^4 + residual. Extract α, βσ, δ by non-linear regression.

**Instrumentation:** precise bitflux drivers, calorimetric energy sensors, synchronized measurement of S_comm and I_sem (via bit counters + Landauer conversion)

**Notes:** Must correct for baseline E0 and other contributions (Ψ terms) — either measure them independently or include as fit parameters with priors. Ensure δ>0 constraint in regression (regularized fit).

**Uncertainty:** model mismatch (missing higher-order terms), measurement noise. Use bootstrap to estimate confidence intervals and perform goodness-of-fit tests.

---

### 5) Reference parameters (C0, E_ref) & dynamic rates (k_C, k_Psi)
**C0:** measure typical flux on target channel using long-run averaging of Φ_info (bits/(m^2*s)). Use environment controls.

**E_ref:** chosen per protocol (e.g., Landauer single-bit at Tref or practical channel energy). Document choice clearly.

**k_C, k_Psi (decay rates):** perturb the system (step change in Φ_info or coherent excitation) and record relaxation of C(t) or Ψ(t). Fit exponential decay \(x(t) = x_{eq} + A e^{-t/τ}\) then k = 1/τ.

Instrumentation: high-speed acquisition (sample rate >> expected k). For quantum modes, use coherence-time measurement techniques.

A short summary of formulae to compute parameters from observables:

- **λ':** \(\lambda' = R_{meaningful}/R_{total}\)

```tex

\documentclass{article}
\usepackage{amsmath,amssymb,amsthm}
\newtheorem{lemma}{Lemma}
\newtheorem{theorem}{Theorem}
\begin{document}

\title{B4: Estimates and Lemmas for Lyapunov Proof}
\author{UET team}
\maketitle

\section*{Notation}
Let $V\subset\mathbb{R}^n$ be a bounded domain with smooth boundary. We use $\|\cdot\|_{L^p}$ and $\|\cdot\|_{H^1}$ as standard norms.

\section*{Functional}
We consider
\[\Omega[C,\Psi]=E - C S + \frac{\alpha}{2}C^2 + \frac{\delta}{4}C^4 + \hbar_C\int_V |\Psi|^2 + \kappa\int_V |\nabla\Psi|^2 + \gamma\int_V C|\Psi|^2.
\]

\begin{lemma}[Coercivity of \Omega]
Assume $\delta>0$, $\kappa>0$, $\hbar_C>0$. Then there exist constants $a,b>0$ and $C_0\ge0$ such that
\[\Omega[C,\Psi] \ge a \|\Psi\|_{H^1(V)}^2 + b\|C\|_{L^4(V)}^4 - C_0.
\]
\end{lemma}

\begin{proof}[Sketch]
Use positivity of quartic term and Poincar\'e/Sobolev embedding to lower-bound the gradient term; absorb linear terms via Young inequality.
\end{proof}

\begin{lemma}[Control of coupling term]
For any $\epsilon>0$ there exists $C_\epsilon$ s.t.
\[\left|\gamma\int_V C|\Psi|^2\right| \le \epsilon \|C\|_{L^4}^4 + C_\epsilon \|\Psi\|_{H^1}^2.
\]
\end{lemma}

\begin{proof}[Sketch]
Use H\"older and Gagliardo--Nirenberg interpolation to split norms and Young's inequality to absorb into coercive terms.
\end{proof}

\begin{theorem}[A priori energy bounds]
Under assumptions on initial data $C_0\in H^1\cap L^4$, $\Psi_0\in H^1$, the dissipative gradient-flow system has global weak solutions satisfying
\[\sup_{t\in[0,T]} \left(\|C(t)\|_{L^2}^2 + \|\Psi(t)\|_{H^1}^2\right) \le M(T)
\]
for some finite $M(T)$ depending on data and parameters.
\end{theorem}

\begin{proof}[Sketch]
Multiply PDEs by $C$ and $\bar\Psi$, integrate over $V$, use Lemmas to bound coupling and apply Gr\"onwall.
\end{proof}

\end{document}
```

## Insight (สิ่งสำคัญที่สุด)
Pick **message/event** as atomic unit. Let
- `C` = messages / (m²·s) (event flux per unit area)  
- `S_comm`, `I_sem` = bits per message (not bits/s)  
Then the product `C * (S_comm − λ' I_sem)` has units bits/(m²·s). Convert bits→J by `k_B T ln 2` to obtain energy rate per unit area (J/(m²·s)). Multiply by a reference area or integrate over the domain to obtain energy rates (J/s), and multiply by Δt_ref (default 1 s) to get Joules — thus Ω can be assembled as an energy (J). Choose |Ψ|² units = bits/(m³·s) and ℏ_C units = J·s/bit so ℏ_C ∫|Ψ|² dV → J.

3. `I_sem` — **semantic bits per message**: bits / message. `λ'` dimensionless semantic fraction; typical `0≤λ'≤1`.
4. `k_B` — Boltzmann constant: 1.380649e-23 J/K. `T` — temperature in K (must be recorded per dataset). Use `E_bit = k_B T ln 2`.
5. `Δt_ref` — reference time window for conversion (default 1 s). Use different Δt only if explicitly required and recorded.
6. `Ψ_C` (Psi) — choose units: sqrt(bits/(m³·s)). Then `|Ψ|^2` has units bits/(m³·s).
7. `ℏ_C` (hbar_C) — choose units: J·s/bit. Then ℏ_C * ∫|Ψ|^2 dV has units (J·s/bit) × (bits/s) = J.
8. `Φ(C)` — interaction potential: Joules (energy). If Φ is density-like (per m²), document and integrate appropriately.
9. `Ω` — target: Joules. Build Ω as energy in the chosen reference time Δt_ref.
10. `k_C`, `k_Ψ` — mobilities: 1/s (gradient flow rates). Document units in code and notebooks.

## Plain‑Language Summary (One Paragraph)
เราศึกษาสมการสองฟิลด์ที่แลกพลังงานกัน (ตัวแปร **C** และคลื่นเชิงซ้อน **Ψ**). เราออกแบบฟังก์ชันพลังงาน **Ω** ให้ทำงานเหมือน “ระดับพลังงาน” ของระบบ แล้วพิสูจน์แบบร่างว่า ระบบควรลด **Ω** ลงเมื่อเวลาผ่านไป (จึงไม่ระเบิดง่าย). จากนั้นเราใช้ตัวแก้สมการตัวเลขแบบ **semi‑implicit** ซึ่งทนพารามิเตอร์ที่แข็ง (ค่า **K** ใหญ่) ได้ดี และแสดงผลอย่างเป็นระบบ: เทียบกับวิธี explicit, สแกนพารามิเตอร์, สร้างแผนที่เฟส และทดสอบความทนทานทั้งแบบสุ่มและแบบเจาะจงความถี่ย่านสูง (hi‑k). ผลลัพธ์บ่งชี้ว่า มี “โซนปลอดภัย” กว้างที่ระบบเสถียรและพลังงานลดลงสม่ำเสมอ ทั้งใน 2D และ 3D.

---

## 1. Model (Dimensionless) and Energy Functional
We analyze the following nondimensional system (balanced scaling; periodic BC):

\[\begin{aligned}
\partial_t C &= -\Big( -S + a\,C + d\,C^3 + G\,|\Psi|^2 \Big),\\
\partial_t \Psi &= -\Big( h\,\Psi - K\,\Delta \Psi + G\,C\,\Psi \Big),
\end{aligned}\]

with constants \(a,h>0\), stiffness \(K\gg 1\) in the Ψ‑sector, small quartic \(d\ge 0\), and small source/bias \(S\). The energy (Lyapunov candidate) is

\[\Omega[C,\Psi] = \int \Big( \tfrac{1}{2} a C^2 + \tfrac{1}{4} d C^4 + h|\Psi|^2 + K|\nabla\Psi|^2 + G C|\Psi|^2 \Big)\,dV\; -\; S\int C\,dV.\]

> **Nominal operating point (used across runs):** \(a=h=1\), \(d\approx 1.7\times 10^{-12}\), \(S\approx 2.9\times 10^{-4}\), \(K \in [10^3,3\times 10^5]\), \(G \in [0.25,2.0]\).

---

## 2. Variational Structure & Lyapunov Sketch (A3)
Under the gradient‑like split \(\partial_t C = -\delta\Omega/\delta C\), \(\partial_t \Psi = -\delta\Omega/\delta \Psi^*\), the chain rule gives
\(\tfrac{d\Omega}{dt} = -\int \big|\delta\Omega/\delta C\big|^2 dV - \int \big|\delta\Omega/\delta \Psi\big|^2 dV \le 0\).
In our discrete scheme, we enforce a **semi‑implicit** treatment on the stiff Ψ‑Laplacian which yields a **discrete energy non‑increase** up to sampling tolerance; see Sections 4–6 for evidence.

> **Assumptions**: periodic BC; bounded coefficients; timestep small enough that the discrete residual of the split scheme remains contractive in the Ψ‑sector.  
> **Open theoretical item**: full coercivity proof for the \(G C|\Psi|^2\) coupling under all \(G>0\) (empirically well‑behaved in our ranges; see Sec. 6).

---

## 3. Numerical Method (B1–B3)
We employ a split scheme on a uniform grid (2D: 64²; 3D: 32³):

- **C‑update (explicit):** \(C^{n+1} = C^n + \Delta t\,\big[-(-S + aC^n + d(C^n)^3 + G|\Psi^n|^2)\big]\).
- **Ψ‑update (semi‑implicit):** solve \((I - \Delta t\,K\,\Delta)\,\Psi^{n+1} = \Psi^n - \Delta t\,(h\Psi^n + G C^n \Psi^n)\) in Fourier space.
- **Energy evaluation:** spectral gradients for Ψ; composite integrals for Ω.

**Neutrality checks.** (i) Explicit vs semi‑implicit at same dt (explicit blows up for large K). (ii) dt‑scan to show semi‑implicit monotone Ω for a practical dt window. (iii) Bias analysis: semi‑implicit (large dt) vs explicit (tiny dt) yield comparable physics metrics and spectra.

**Evidence:** B1, B2, B3 reports in the Evidence Pack.

---

## 4. Phase Map & Criteria (C1–C4)
We define **C2 criteria** for pass/fail:
1) no divergence; 2) \(\Delta\Omega\le \text{tol}\) with \(\text{tol}=10^{-8}|\Omega_0|+10^{-10}\);  
3) **quasi‑monotone** Ω: fraction of upward jumps ≤5% and max jump ≤ \(10^{-4}|\Omega_0|\);  
4) amplitude ratio \(\le 10\times\).

**Findings.** 2D coarse & fine sweeps (C1, C3) over \(K\in\{10^3\ldots 3\times 10^5\}\), \(G\in\{0.25\ldots 2.0\}\) show a broad region of passes; 3D spot‑checks (C4, 32³) agree.

**Evidence:** C1, C2, C3, C4 reports.

---

## 5. Robustness Campaigns (D1–D3)
- **D1 MC‑boost (3D)**: 16 randomized ICs (Gaussian‑smoothed perturbations). High pass fraction; Ω(t) smooth & non‑increasing.
- **D2 Optimization‑up (3D)**: multi‑Fourier basis (low/mid/high‑k) searching worst cases under amplitude caps; **no significant positive ΔΩ**; amp_ratio within bounds.
- **D3 Targeted hi‑k (3D)**: stress tests at component magnitudes {4,6,8,10,12} across axes/diagonals; **all pass**; ΔΩ ≤ 0.

**Evidence:** D1, D2, D3 reports.

---

## 6. Results Summary & Safe Operating Region
- **Energy behavior:** Ω decreases monotonically (within numerical tolerance) in all reported runs.
- **Safe region (empirical):** \(K \gtrsim 10^4\) and \(0.5 \lesssim G \lesssim 2.0\) on 64²/32³, \(\Delta t\in[10^{-4},5\times10^{-4}]\); extends to 3D spot‑checks.
- **Neutrality:** large‑dt semi‑implicit matches tiny‑dt explicit on physics metrics and spectra (B3).

> **Practical guidance:** for large K, prefer semi‑implicit Ψ with FFT; retain explicit C under current parameters; adopt C2 criteria as automated guards.

## 2. Locked variable definitions & units (v2)

   - **Unit:** Joules (J) or J/s for rates. \(\lambda'\) remains dimensionless fraction.

4. **\Psi_C — communication quantum amplitude**
   - **Meaning:** Complex amplitude for coherent communication modes.
   - **Proposed unit:** \(\sqrt{\mathrm{bits/s}}\) (so \(|\Psi_C|^2\) has units bits/s), OR choose amplitude units that make \(\hbar_C|\Psi_C|^2\) energy density after normalization.
   - **Normalization:** Choose scaling so \(\hbar_C|\Psi_C|^2\) yields Joules when integrated over relevant domain.

5. **\hbar_C — effective Planck constant (communication)**
   - **Meaning:** Scaling constant mapping quantum amplitude density to energy.
   - **Unit requirement:** J·s × (norm factor) — defined so \(\hbar_C|\Psi_C|^2\) = J.

6. **\Phi(C) — interaction potential**
   - **Meaning:** Collective communication potential energy.
   - **Unit:** Joules (J); if intensive, specify J/m^3.

7. **E — total energy**
   - **Meaning:** Physical energy of the system.
   - **Unit:** Joules (J).

8. **\Omega — UET functional**
   - **Meaning:** Unified energy functional.
   - **Unit:** Joules (J).

## 3. Conversion rules & formulas

### Landauer conversion (bits → J)
\[E_{\rm bit}(T) = k_B T \ln 2\]
With \(k_B = 1.380649\times 10^{-23}\ \mathrm{J/K}\).

**Numeric at T = 300 K:**
- \(k_B T = 1.380649\times 10^{-23} \times 300 = 4.141947\times 10^{-21}\ \mathrm{J}\).
- Multiply by \(\ln 2 \approx 0.693147\):
  \(4.141947\times 10^{-21} \times 0.693147 \approx 2.87\times 10^{-21} \ \mathrm{J}\).

So \(E_{\rm bit}(300\,\mathrm{K}) \approx 2.87\times 10^{-21}\,\mathrm{J}.\)

**Bits/s → J/s (power):**
\[P_{\rm info} = R\cdot k_B T \ln 2\quad(\mathrm{J/s})\]
where \(R\) is bits/s.

**Bits/s → energy over Δt:**
\[E = R\cdot k_B T \ln 2 \cdot \Delta t\]

### Mapping the Ω coupling term
We adopt the dimensionless-normalized form:
\[\Omega \ni C\bigl(S_{\rm comm} - \lambda' I_{\rm sem}\bigr)\]
where both \(S_{\rm comm}\) and \(I_{\rm sem}\) are expressed in Joules.

If you have raw signals:
- \(\Phi_{info}\) (bits/(m^2·s)) → compute normalized \(C = \Phi_{info}/C_0\).
- \(S_{raw}\) (bits/s) → convert to \(S_{\rm comm} = S_{raw}\cdot k_B T \ln 2 \cdot \Delta t\) (J over window Δt).

This guarantees the product has unit Joules.

## 1. นิยามพารามิเตอร์ (units, physical meaning, formula)

### 1.1 \(\hbar_C\) — effective Planck constant for communication
- **Role:** แปลงความหนาแน่นเชิงความน่าจะเป็นของสนามสื่อสาร (amplitude) ให้เป็นพลังงาน
- **Requirement (unit):**
  \[ [\hbar_C] = \frac{\mathrm{J}\cdot\mathrm{s}}{\mathrm{bit}}. \]
  เพราะ \(|\Psi_C|^2\) ถูกกำหนดให้มีหน่วย bits/s, ดังนั้น \(\hbar_C[\tfrac{\mathrm{bits}}{\mathrm{s}}] = \mathrm{J}\).
- **Interpretation:** ค่าขนาดของ \(\hbar_C\) เป็นตัวกำหนด "energy per coherent bit per unit phase-time" ในระบบ

### 1.2 \(\kappa\) — gradient stiffness (kinetic coefficient)
- **Role:** คูณกับ \(\|\nabla\Psi_C\|^2\) เพื่อให้เทอม gradient มีหน่วยพลังงาน
- **Unit requirement:** ให้ \(\|\nabla\Psi_C\|^2\) มีหน่วย (bits/s)/m^2, ดังนั้น
  \[ [\kappa] = \frac{\mathrm{J}}{(\mathrm{bits/s})/\mathrm{m}^2} = \mathrm{J}\cdot\frac{\mathrm{m}^2\cdot\mathrm{s}}{\mathrm{bit}}. \]
- **Interpretation:** แข็งแรงเมื่อ \(\kappa\) สูง — ลดการแปรผันเชิงพื้นที่ของโหมดสื่อสาร

### 1.3 \(\alpha,\beta,\delta\) — potential coefficients (polynomial in C)
- **Role:** ให้พจน์ \(\tfrac{\alpha}{2}C^2\), \(\tfrac{\delta}{4}C^4\), และเทอมเชิงกลยุทธ์ที่รวม \(\beta\sigma\,C^2\).
- **Units:** เพราะ C dimensionless → \([\alpha]=[\beta\sigma]=[\delta]=\mathrm{J}.\)
- **Constraints for stability:** \(\delta>0\) และ \(\alpha+\beta\sigma>0\) (convexity near C=0)

### 1.4 \(\lambda'\) — semantic fraction (dimensionless)
- **Role:** สัดส่วนของบิตที่มีความหมายเชิง semantic; 0 ≤ \(\lambda'\) ≤ 1 in principle.
- **Unit:** dimensionless

## 2. Stability & boundedness conditions (mathematical)

We require \(\Omega\) to be bounded below and act as a Lyapunov function for gradient flow.

### 2.1 Polynomial dominance
- Require \(\delta>0\) so that for large \(|C|\), the \(C^4\) term dominates and \(\Omega\to +\infty\). This prevents runaway at large C.

### 2.2 Local convexity
- Near \(C=0\) require \(\alpha+\beta\sigma>0\) so quadratic term is positive definite.

### 2.3 Positivity of field terms
- \(\kappa>0\) and \(\hbar_C>0\) to ensure gradient and quantum contributions are nonnegative.

### 2.4 Lyapunov condition for C-gradient flow
With \(\dot C = -k_C \partial_C \Omega\), monotonic decrease of \(\Omega\) follows if boundary conditions make surface terms vanish. Standard requirement: \(k_C>0\).

## 3. Choice of reference energy scale and nondimensionalization
**Why:** Direct search in raw SI units is inefficient and often poorly conditioned. Define a reference energy \(E_{ref}\) to scale coefficients to dimensionless or order-1 numbers.

### 3.1 Suggested reference definitions
- **Option 1 (communication energy):** \(E_{ref} = C_0\cdot S_{ref}\cdot \Delta t\) where \(C_0\) is reference flux (bits/(m^2·s)), \(S_{ref}\) is typical per-area info rate (bits/s) converted to J via Landauer, and \(\Delta t\) is time window (1 s). This ties E_ref to actual communicative power.

- **Option 2 (thermal quantum):** \(E_{ref} = k_B T_{ref} \ln 2\) (single-bit Landauer energy). Use when studying minimal energy regimes.

Set scaled parameters: \(\tilde{\alpha} = \alpha/E_{ref}\), etc.

## Model (toy, single-site)
**Ω functional (toy)** — สั่งสมโดยย่อให้เก็บพจน์สำคัญเพียงไม่กี่ตัว

\[
\Omega(C) = E - C\,S + \frac{\alpha}{2}C^2 + \frac{\delta}{4}C^4
\]

โดยที่
- \(S\) คือ \(S_{\rm comm} - \lambda' I_{\rm sem}\) ในหน่วย Joules (ให้พิจารณาค่า S เป็นพารามิเตอร์ที่กำหนดจากการ mapping ของ Part A2/A3).  
- เราละเว้นเทอม \(\hbar_C|\Psi|^2\) และ \(\kappa\|\nabla\Psi\|^2\) ใน toy model แรกเพื่อความเรียบง่าย (สามารถใส่กลับในขั้นถัดไป)

**Gradient flow rule for C:**
\[
\dot C = -k_C \frac{\partial \Omega}{\partial C} = -k_C\left(-S + \alpha C + \delta C^3\right)
\]
หรือเขียนเป็น
\[
\dot C = k_C\,S - k_C\alpha C - k_C\delta C^3.
\]

**Fixed points** satisfy \(\partial_C \Omega = 0\):
\[\alpha C + \delta C^3 = S.\]

**Stability of a fixed point C\*:** linearize: eigenvalue = \(-k_C (\alpha + 3\delta C_*^2)\). If \(\alpha + 3\delta C_*^2 > 0\) then eigenvalue negative → stable.

## Toy simulation pseudocode (Python-like)

```python
# Toy simulation of C-gradient-flow
import numpy as np
from math import isfinite

def simulate_C(alpha, delta, kC, S, C0=0.1, dt=0.01, T=100.0):
    steps = int(T/dt)
    C = C0
    Omega_hist = []
    C_hist = []
    t_hist = []
    for n in range(steps):
        t = n*dt
        # compute Omega
        Omega = E - C*S + 0.5*alpha*C**2 + 0.25*delta*C**4
        dC = kC*S - kC*alpha*C - kC*delta*C**3
        C = C + dt * dC  # Euler; replace with RK4 for accuracy
        C_hist.append(C)
        Omega_hist.append(Omega)
        t_hist.append(t)
        # quick safety check
        if not isfinite(C) or abs(C) > 1e6:
            return {'status':'diverged','t':t,'C':C}
    return {'status':'ok','t':T,'C':C,'C_hist':np.array(C_hist),'Omega_hist':np.array(Omega_hist),'t_hist':np.array(t_hist)}
```

**Notes:**
- Use RK4 or solve_ivp for stability in real runs.
- Use adaptive dt if stiffness observed.
