# UET v5.0 — Frontend Page Inventory & Layout Audit (Updated)

อ้างอิงจากการปรับโครงสร้างล่าสุด เราได้ระบุ **5 เพจหลัก (Heavy Pages)** และปรับชื่อ/หน้าที่การทำงานให้ตรงกับคอนเซปต์ของแพลตฟอร์มมากที่สุดครับ โดยเพจหลักจะมี Subsets ย่อยในตัวมันเอง ดังนี้:

---

## 🏆 The 5 Heavy Pages (5 เพจหลักของระบบ)

### 1. 📰 News (`/news`) 
*อารมณ์คล้าย Google Search ที่มีระบบถกเถียงด้านหลัง*
- **Layout:** AppShell + Bento Grid
- **การทำงาน:** หน้าหนักที่สามารถโฟสต์ข่าวหรือเนื้อหามาจาก **Project** ได้เลย เพื่อให้ง่ายต่อการศึกษาต่อ
- **รูปแบบ:** การ์ดข่าว (Slide) ที่โชว์โปรไฟล์ของ Project บนช่องใดช่องหนึ่งของ Bento Grid พอกดแล้วเด้งเข้า Project นั้นๆ ทันที

### 2. 🤖 WorkChat (`/workchat`)
*อารมณ์คล้าย NotebookLM สำหรับวิเคราะห์และจดบันทึก*
- **Layout:** Three-Panel Layout (ต้องเริ่มต้นมาด้วยสัดส่วน 3 คอลัมน์ที่สมมาตรเท่ากันเป๊ะๆ)
  - **Panel 1 (Left):** แหล่งข้อมูล (Source) สำหรับอัปโหลดไฟล์ / เลือกเอกสารอ้างอิง
  - **Panel 2 (Center):** แชท Agent หลัก (คุยกับ AI)
  - **Panel 3 (Right):** Studio Panel สำหรับจด Note โน้ตย่อหรือใช้ Tool ต่างๆ (เน้นใช้สำหรับเขียนงานสรุป .md)

### 3. 🌐 Community (`/community`) *(แทนที่ /feed เดิม)*
*อารมณ์คล้าย Facebook + IG + Telegram*
- **Layout:** Three-Panel Layout (เริ่มต้นสมมาตรเท่ากัน)
  - **Panel 1 (Left):** Profile ของผู้ใช้ (อารมณ์ IG) โชว์ประวัติส่วนตัว, รูป, สตอรี่, ภาพผลงาน (หมายเหตุ: **Profile ≠ Account** Profile คือส่วนแสดงตัวตน)
  - **Panel 2 (Center):** ฟีด Community ตรงกลางให้โพสต์และอ่านข่าวสาร
  - **Panel 3 (Right):** แชทเพื่อน และ แชท Community (กลุ่มใหญ่คล้าย Telegram) สำหรับชิทแชททั่วไป

### 4. 🗂️ Project (`/project`) *(แทนที่ /workspaces เดิม)*
*อารมณ์คล้าย Discord + Obsidian*
- **Layout:** Sidebar Layout
- **ส่วนจัดการการสื่อสาร (Ref: Discord):** แชท (เรียกว่า **Topic** ไม่ใช่แชนแนล), กำหนด Role คนในโปรเจกต์, โทรเสียง, วิดีโอคอล, แชร์หน้าจอ (ฟังก์ชั่นนี้จะไม่ให้ซ้ำกับเบื้องต้นที่แชททั่วไปทำได้)
- **ส่วนจัดการไฟล์ (Ref: Obsidian):** การสร้างโฟลเดอร์/สร้างไฟล์ .md, แก้ไข, ลบ, อัปโหลด, ดาวน์โหลด
- **โครงสร้างไฟล์พิเศษ:** รองรับการตั้งค่าเทมเพลต .md เพื่อสร้างหน้า "Profile/Landing Page" ของโปรเจกต์เอง เอาไว้โชว์สมการและรายงาน (แต่ไม่รองรับถึงขั้นเขียน App ขึ้นมาในนี้)
- **Shared Functions:** สามารถเรียกใช้ Panel Chat Agent และ Panel Studio พ่วงเข้ามาใช้งานในระดับโปรเจกต์ได้ 
- **⚠️ ฟีเจอร์ชูโรง:** แต่ละโปรเจกต์จะมี **Wallet ของตัวเอง 1 Account** เพื่อใช้แชร์ค่า Credits จ่ายให้ AI ของโปรเจกต์ และรองรับการ "รับบริจาค" จากคนนอกได้

### 5. 💰 Economy & Account (`/economy` และ `/account`)
*ศูนย์รวมข้อมูลทรัพยากร ระบบเหรียญ และ API แบบครบวงจร*
- **Layout:** AppShell + Bento Grid โชว์ KPI Dashboard ตามระบบที่ผูกกัน
- **`Account` (มุมมองทรัพยากรส่วนตัวผู้ใช้):** มีเพจย่อยคือ `/account/wallet`, `/account/apikey`, `/account/billing`, `/account/credits`, `/account/mining`, `/account/market`, `/account/pricing`
- **`Economy` (มุมมองเชิงระบบ/ภาพรวม):** มีเพจย่อยคือ `/economy/wallet`, `/economy/apikey`, `/economy/billing`, `/economy/credits`, `/economy/mining`, `/economy/market`

### 📝 กฎเหล็กประจำสถาปัตยกรรม (Architecture Rules)
- **แชท 2 ประเภทแยกกันชัดเจน:** 
  1. **Community Chat**: กลุ่มใหญ่ คุยกับชุมชน คุยสัพเพเหระ (อยู่ใน /community)
  2. **Topic Chat**: ช่องแชทเฉพาะเรื่องใน `/project` ใช้สำหรับถกเถียงและคุยงานเท่านั้น (ห้ามสับสนกันในแง่ Database)
- **Profile vs Account:** "Profile" คือประวัติ (อวดงาน) แต่ "Account" คือตัวเลข ทรัพยากร (เงิน/API/การใช้กราฟิก)
- หน้า Layout แบบ 3-Panel ตอนโหลดขึ้นมาเริ่มต้น **ต้องมีขนาดความกว้างเท่ากัน 3 ช่อง (สมมาตร)** เสมอ จากนั้นค่อยปรับยืดหดได้ทีหลัง
