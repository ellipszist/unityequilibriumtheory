# UET Standards Hub

This folder defines the current repository standards that govern metadata, claim language,
topic documentation, and verification artifacts.

Normative files for this release:

- [documentation_style_guide.md](./documentation_style_guide.md)
- [topic_readme_standard.md](./topic_readme_standard.md)
- [verification_contract.md](./verification_contract.md)
- [release_checklist.md](./release_checklist.md)
- [UET_Framework_v1.0.md](./UET_Framework_v1.0.md)
- [incubator_workflow_standard.md](./incubator_workflow_standard.md)

Scope of these standards:

- Align release metadata across `README`, `docs/README`, `CITATION.cff`, and package metadata
- Standardize evidence wording and readiness levels
- Make topic README structure predictable
- Require reproducible verification artifacts with explicit config, metrics, and thresholds
- Mark legacy material as archive-only unless promoted back into current standards
