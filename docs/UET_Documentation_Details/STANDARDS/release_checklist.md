# Release Checklist

Use this checklist before publishing or announcing a repository release.

- Confirm `docs/meta/release_manifest.json` version and date.
- Align `README.md`, `docs/README.md`, `CITATION.cff`, `docs/CITATION.cff`, and `pyproject.toml`.
- Recompute or reconfirm topic directory and test counts.
- Review top-level badges and summary wording against canonical metadata.
- Update claim inventory for any wording that changed in landing pages or flagship topics.
- Confirm that standards links resolve and archive warnings remain visible.
- Confirm dataset manifest entries exist for any newly normalized flagship topic.
- Confirm topic readiness map reflects current status labels.
- Confirm no restricted wording appears in academic docs without explicit justification.
