# 🏛️ Unity Equilibrium Theory (UET) Framework v1.0 Standard

This document defines the mandatory standards for all research topics, code, and documentation within the UET ecosystem to ensure scientific rigor, code integrity, and optimal Answer Engine Optimization (AEO).

## 📂 1. Directory Structure Standards

- **Docs/**: Unified official documentation (Theory, API, Standards).
- **topics/**: Research domains following the 5x4 grid.
  - **Doc/**: Original research reports, math derivations, and papers.
  - **Code/**: Implementation scripts (Engine, Proof, Research, Competitor).
  - **Data/**: Real-world data files.
  - **Result/**: Performance logs and figures.

## 🤖 2. Answer Engine Optimization (AEO)

All `README.md` files must include an **AI-Digest** block at the top:
- **Summary**: ~50 words.
- **Languages**: English and Thai (preferred).
- **Purpose**: To provide Google AI Overviews with a clean, low-entropy summary of the research.

## 🧪 3. The Triple-Green Standard

1. **Pass Rate**: 100% on all core tests.
2. **Architecture**: Mandatory adherence to the 5x4 structure.
3. **Integrity**: Zero arbitrary parameters; all constants derived from first principles.
