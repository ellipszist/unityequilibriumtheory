# Contributing to UET (การมีส่วนร่วมกับโปรเจกต์)

ยินดีต้อนรับสู่นักวิจัย นักพัฒนา และนักคิดทุกคน! UET เป็นโปรเจกต์โอเพนซอร์ส (Open Source) ที่เชื่อว่าความรู้ควรเปิดกว้าง การจะสร้างทฤษฎีที่รวมทุกศาสตร์เข้าด้วยกันนั้นไม่สามารถทำได้โดยคนๆ เดียว เราต้องการความช่วยเหลือจากคุณ

## 🌟 คุณช่วยอะไรได้บ้าง?

คุณไม่จำเป็นต้องเป็นนักฟิสิกส์ควอนตัมเพื่อช่วยเหลือโปรเจกต์นี้ เราเปิดรับความช่วยเหลือในหลายๆ ด้าน:

1. **Software Engineering:**
   - พัฒนาและเพิ่มประสิทธิภาพ Rust Core Engine
   - ปรับปรุง UI/UX ของ Next.js Frontend
   - สร้างไลบรารี Python SDK ให้สมบูรณ์ขึ้น

2. **Data Science & AI:**
   - ทดสอบและปรับจูน RAG / Vector Database สำหรับ Knowledge Base
   - นำข้อมูลดิบมาทำ Simulation เพื่อพิสูจน์สมการต่างๆ

3. **Technical Writing & Translation:**
   - ช่วยแปลเอกสาร (Documentation) เป็นภาษาต่างๆ (จีน, สเปน, ญี่ปุ่น)
   - อธิบายสมการคณิตศาสตร์ให้คนทั่วไปเข้าใจง่ายขึ้น (เขียน Tutorials)

4. **Peer Review:**
   - ตรวจสอบสมการ หาช่องโหว่ หรือข้อผิดพลาดทางตรรกะในทฤษฎี

---

## 🛠 ขั้นตอนการส่งโค้ด (Pull Request Process)

หากคุณต้องการแก้ไขโค้ดหรือเอกสาร กรุณาทำตามขั้นตอนเหล่านี้:

1. **Fork the repository** ไปยังบัญชี GitHub ของคุณ
2. **Create a new branch** สำหรับฟีเจอร์หรือการแก้ไขของคุณ (เช่น `feat/new-simulation-engine` หรือ `fix/typo-in-docs`)
3. **Commit your changes** เขียน Commit message ให้ชัดเจนว่าคุณทำอะไร
4. **Push to the branch** ดันโค้ดขึ้นไปที่ GitHub ของคุณ
5. **Open a Pull Request (PR)** ระบุรายละเอียดว่า PR นี้แก้ปัญหาอะไร และแนบเลข Issue ถ้ามี

*หมายเหตุ: โปรดรันคำสั่ง `cargo test` (สำหรับ Rust) หรือ `npm run lint` (สำหรับ Frontend) ก่อนส่ง PR ทุกครั้ง*

## 📜 รูปแบบการเขียนโค้ด (Code Style Guidelines)

เพื่อให้โค้ดอ่านง่ายและเป็นระเบียบ:
- **Rust:** ใช้มาตรฐานของ `rustfmt` เสมอ
- **TypeScript / React:** ใช้ `Prettier` และ `ESLint` ตามที่ตั้งค่าไว้ในโปรเจกต์
- **Python:** ยึดตามหลัก PEP 8 และเขียน Type Hints เสมอ
- **Markdown:** ใช้ Markdown lint และถ้ามีสมการคณิตศาสตร์ให้ใช้ฟอร์แมตของ KaTeX (`$$...$$` สำหรับบล็อก และ `$...$` สำหรับแทรกในบรรทัด)

---

## 🐞 การรายงานบั๊ก (Reporting Bugs)

หากพบข้อผิดพลาด โปรดสร้าง Issue บน GitHub พร้อมรายละเอียดดังนี้:
1. ปัญหาที่พบคืออะไร?
2. ขั้นตอนในการทำให้เกิดบั๊กซ้ำ (Steps to reproduce)
3. สภาพแวดล้อมของคุณ (OS, เวอร์ชันของ Node/Rust/Python)

---

ขอบคุณที่ให้ความสนใจและร่วมเป็นส่วนหนึ่งของการผลักดันพรมแดนแห่งความรู้ไปด้วยกัน! 🚀
