# UET Documentation Details

This folder is the main documentation layer for understanding the Unity Equilibrium Theory
project.

It should be the first place a reader opens before diving into historical archives, topic
folders, or legacy paper material.

## Purpose

This documentation tree exists to make the project readable in the correct order:

1. what UET is trying to be
2. where it came from
3. what the core equation and axioms are
4. how the project checks itself against evidence
5. where older context lives if deeper history is needed
