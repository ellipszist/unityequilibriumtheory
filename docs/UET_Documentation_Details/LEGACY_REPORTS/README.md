# Legacy Reports Archive

This directory is preserved as an archive of historical notes, drafts, pitch material,
older analyses, and previous documentation structures.

Archive policy for this release:

- Files in this directory are not the normative source for release metadata.
- Files in this directory are not the normative source for approved claim wording.
- Historical material may still be useful for provenance, context, or migration work.
- If a legacy document becomes authoritative again, it should be promoted into the current
  standards or documentation tree with an explicit review pass.
