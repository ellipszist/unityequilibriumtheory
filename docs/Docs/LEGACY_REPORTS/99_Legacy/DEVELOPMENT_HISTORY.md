### Phase 2: Rebuild Foundation (v0.8.7 Early)

**สิ่งสำคัญ**:
- ไม่เคยเริ่มจากศูนย์ — เริ่มจาก **ข้อผิดพลาดเดิม + ต่อยอด**
- ข้อมูลเก่าทั้งหมดอยู่ใน archive

**ผลลัพธ์**: คำนวณได้ + อธิบายได้
