## Preprocessing

- Primary verifier uses vacuum wavelengths from the NIST hydrogen working copy.
- It computes the Rydberg geometric term from parsed transitions.
- It compares predicted vacuum wavelengths from CODATA `R_H` against NIST vacuum wavelengths.
- It writes a formula bridge manifest that records inherited photon, de Broglie, Bohr, hydrogenic, and Rydberg formula roles plus cross-topic UET dependencies.
- It compares rounded hydrogen `n=1..8` energy rows against the NIST ionization-energy anchored `E_n = -13.5984/n^2` relation.
- It computes selected He+ and Li2+ reduced-mass hydrogenic residuals against source-referenced EUV rows, records C VI as a higher-Z stress test, and emits a hydrogen-like domain-coverage gate so represented `Z`, benchmark lanes, source-status counts, same-transition coverage, and missing broad-validation requirements are machine-readable.
- It records 1S-2S, Lamb shift, and 21 cm hyperfine as precision source targets, then computes nonrelativistic, leading Dirac, empirical Lamb-handoff 1S-2S residuals, 21 cm wavelength bookkeeping, and a leading Fermi-contact 21 cm residual.
- It records neutral He I visible rows as many-electron source targets without computing neutral-helium residuals.
- It computes hydrogen line transcription-bound residual diagnostics, neutral He I photon energies, records NIST term assignments, derives air/vacuum medium-normalized wavelengths, checks source line-component/blend policy, computes ground-state baseline residual diagnostics, prepares excited-state target energies, sizes a zero-quantum-defect hydrogenic residual baseline, computes a fixed-parameter screening baseline, runs a limited same-series quantum-defect leave-one-out prediction gate, checks same-source-family NIST holdout rows with transcription-rounding bounds, classifies holdout wavelength medium using the NIST convention, predicts restricted vacuum ground-state holdout wavelengths, skips standard-air holdout rows pending conversion policy, audits legacy multi-electron scripts as non-evidence smoke/demo code, maps UET atomic-operator derivation requirements, emits an internal baseline-comparator table, maps uncertainty readiness by lane, computes residual-to-source-uncertainty budget rows where current source uncertainties or holdout rounding bounds permit it, maps fixed-parameter model readiness by lane, emits a predictive-closure contract, records a baseline-plus-correction predictive-model specification, selects the current narrow first predictive implementation candidate, resolves current operator candidates against the `delta_uet_or_ci` contract, verifies the operator build-spec manifest for implementation-ready I/O and acceptance gates, narrows the external-holdout acquisition target, computes a CHIANTI-vs-current residual cross-check, classifies CHIANTI/current upper-energy source-version deltas separately from wavelength display-rounding consistency, classifies CHIANTI lineage as cross-check-only, validates predictive-v1 parameter-lock and threshold manifests, emits a predictive-v1 diagnostic report, and emits a seven-step predictive-model blueprint before correlated residual modeling.
- Air wavelengths are preserved in the data but not used in the primary metric.
- Topic-level source-evidence and branch-claim gate files keep the accepted hydrogen benchmark separate from blocked precision and many-electron claims.

## Data Policy

- Raw external spectral source captures may later move to `docs/data/external/...`; this topic must still record exact local paths and hashes.
- Hydrogen benchmark, rounded level-energy benchmark, formula bridge, selected He+/Li2+ reduced-mass results, hydrogen-like domain-coverage diagnostics, C VI stress-test result, precision source package, 1S-2S baseline/handoff residual diagnostics, 21 cm source/Fermi diagnostics, residual uncertainty-budget diagnostics, and neutral-helium source/photon-energy/medium/component/ground-baseline/excited-target/hydrogenic-residual/quantum-defect-prediction/holdout/wavelength-medium-classified holdout package cannot be used as evidence for UET-derived `R_H`, broad hydrogen-like ion validation, independent neutral-helium spectral validation, first-principles QED, hyperfine Hamiltonian closure, periodic-table spectra, or many-electron claims.
