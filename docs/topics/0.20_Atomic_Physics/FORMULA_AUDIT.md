# Formula Audit: 0.20_Atomic_Physics

Review status: reviewed registry for the current hydrogen spectrum verifier, atomic engine, and secondary multi-body lanes.

The current primary verifier validates the standard Rydberg wavelength relation against a topic-local NIST hydrogen spectrum working copy and CODATA `R_H`. It also emits an atomic formula bridge manifest so the inherited Bohr/de Broglie/Rydberg chain is explicit instead of implicit, checks hydrogen line transcription-bound residuals, checks selected He+/Li2+ source-referenced rows with a reduced-mass hydrogenic relation, records C VI as a higher-Z stress test, maps hydrogen-like domain coverage, organizes precision spectroscopy targets, computes nonrelativistic and leading Dirac 1S-2S baseline residual diagnostics, applies an empirical Lamb-shift handoff, source-locks 21 cm hyperfine bookkeeping, computes a leading Fermi-contact 21 cm baseline, and computes neutral-helium source photon energies, NIST term assignments, air/vacuum wavelength-medium normalization, line-component/blend policy, ground-state two-electron baseline residual diagnostics, excited-state target energies, a zero-quantum-defect hydrogenic residual baseline, a fixed-screening heuristic baseline, a limited source-calibrated quantum-defect prediction gate, a same-source-family holdout gate, a restricted wavelength holdout gate, and residual-to-source-uncertainty budget rows. These are bounded benchmark/source artifacts, not first-principles UET derivations, and they do not validate QED, recoil, proton-size, hyperfine Hamiltonian corrections, correlated neutral helium spectral residuals, many-electron atoms, independent helium validation, or broad hydrogen-like ion coverage.
