## Formula Audit

### Entry 1: `Massive_Parallel_Harmonic_Interference`

**Relation**

```text
Field_Strength = cos(2 * pi * dist / lambda_saw) * exp(-dist^2 / 100.0)
Potential = 1.0 - Sum(0.5 * (1.0 - noise_level))  # For active nodes where Field_Strength > 0.5
```

**Variables**

| Symbol | Meaning | Unit |
| :-- | :-- | :-- |
| `Field_Strength` | Acoustic pressure generated by a single nozzle | `dimensionless` |
| `dist` | Distance from the nozzle | `nm` |
| `lambda_saw` | Wavelength of the surface acoustic wave | `nm` |
| `Potential` | Local SAW potential (I in Master Equation) | `dimensionless` |
| `noise_level` | Stochastic timing or spatial noise between nozzles | `%` |

**Conversion steps**

| Step | Description |
| :-- | :-- |
| `1` | Calculate distance from each active nozzle in the parallel array. |
| `2` | Determine the spatial field strength using Bessel/cosine functions bounded by a Gaussian envelope. |
| `3` | Superimpose fields. Where fields constructively interfere (Field_Strength > 0.5), they reduce the repulsive Potential toward 0 (forming a trap). |
| `4` | Clamp the final Potential `I` to > 0.0. |
