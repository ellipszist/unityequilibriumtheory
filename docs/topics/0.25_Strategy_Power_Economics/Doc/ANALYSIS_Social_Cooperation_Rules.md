## 2. 📄 Solution: The 3 Rules of Cooperation (3 กฎเหล็กของการร่วมมือ)

จากการจำลองใน UET เราพบว่าการจะทำให้คนมาร่วมมือกัน ไม่ใช่แค่การขอร้อง แต่คือการเปลี่ยน **"แรงตึงของสนาม"** ผ่าน 3 กฎนี้:

### กฎที่ 1: Potential Leveling (การถ่ายโอนความเครียด)
*   **Mechanism:** เมื่อใครคนหนึ่งมีทรัพยากร (C) สูงเกินไป ระบบต้องมีกลไก "ระดับความสูง" (Leveling) เพื่อกระจายความเครียดออกไปสู่เพื่อนบ้าน (Neighbor Sync) 
*   **Action:** การสร้างเครือข่ายแบ่งปัน หรือระบบสนับสนุนที่ทำให้ "ความสำเร็จของหนึ่งคน" กลายเป็น "ความมั่นคงของชุมชน"

### กฎที่ 2: Non-Selfish Boldness (ความกล้าที่ไม่เห็นแก่ตัว)
*   **Mechanism:** ใน Engine คนที่จะช่วยโลกได้คือ Type C (Bold + Not Selfish) 
*   **Action:** เราต้องสนับสนุนคนที่ "กล้าคิดกล้าทำ" แต่ทำเพื่อส่วนรวม (Social Entrepreneurship) ระบบที่ยกย่องคนรวยที่ "ใจดี" จะเสถียรกว่าระบบที่ยกย่องแค่คนรวย

### กฎที่ 3: Visualization of Omega (การมองเห็นความพินาศร่วม)
*   **Mechanism:** คนจะร่วมมือกันเมื่อเห็นว่าการ "สะสมจุดเดียว" ทำให้ระบบโดยรวม (Nature Health) พัง
*   **Action:** การทำให้คนเห็น "ค่าความเหนื่อยล้าของระบบ" (Social Stress) ให้เป็นรูปธรรม จะทำให้เกิดการปรับจูนตัวอง (Self-Correction) โดยอัตโนมัติ
