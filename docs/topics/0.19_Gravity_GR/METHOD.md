# Method

## Problem target

This topic studies whether UET-inspired gravity models can reproduce selected general-relativity and gravity-constant benchmarks.

## Core components

### Engine components
- `Code/01_Engine/Engine_Fluid_Gravity.py`
- `Code/01_Engine/Engine_Gravity_GR.py`

### Proof-oriented components
- `Code/02_Proof/Proof_Equivalence_Principle.py`

### Research and comparison components
- `Code/03_Research/Research_G_Constant.py`
- `Code/03_Research/Research_ShortRange_Gravity.py`

## Variable framing

- Primary modeled quantities: gravitational coupling, metric-like potentials, fluid-gravity terms, and short-range deviation parameters

## Assumptions

- The topic currently uses effective comparison scripts against selected gravity datasets and references.

## Domain of validity

- Selected GR-style, G-constant, and short-range gravity benchmarks represented in topic-local files.

## Excluded cases

- A complete replacement of general relativity across all observational regimes.

## Parameter sensitivity note

- Boundary conditions and fit choices affect the current residuals and should be stated explicitly.
