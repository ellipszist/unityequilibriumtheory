# 🧪 Research Methodology: Acousto-Optic Holography
## 1. Objective
To engineer a tangible, mid-air 3D display using Acoustic Levitation and Optical Projection.

## 2. Experimental Setup
- **Ultrasonic Phased Array:** 40kHz transducers controlled via FPGA for microsecond phase alignment.
- **Particle Canvas:** Bio-safe, lead-free perovskite micro-particles (10-50 micrometers).
- **Projection:** Tri-color RGB laser scanning system aligned with the acoustic nodes.

## 3. The 5x4 Grid Mapping
- **Lattice:** The 3D acoustic pressure nodes forming the grid.
- **Node:** Individual levitated perovskite particles.
