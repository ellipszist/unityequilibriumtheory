# 📥 กล่องขาเข้า (00_Inbox)

## 📌 วัตถุประสงค์
โฟลเดอร์นี้เป็นพื้นที่พักข้อมูลชั่วคราว (Inbox) สำหรับบันทึกความคิดดิบ ทรานสคริปต์การระดมสมอง หรือข้อมูลใหม่ๆ ที่เกี่ยวข้องกับนโยบายและข้อเสนอเชิงระบบของประเทศไทย ก่อนที่จะถูกคัดกรอง เรียบเรียง และจัดหมวดหมู่ลงในพื้นที่หลัก (01-05)

## 📁 โครงสร้าง
- **`raw/`**: พื้นที่เก็บไฟล์ดิบหรือบทสนทนา (Raw Transcripts) ที่ยังไม่ได้รับการสกัดหรือจัดหมวดหมู่
